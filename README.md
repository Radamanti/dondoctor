# DonDoctor - Prueba Técnica de Ingeniero de Datos

## Objetivo

Construir una solución reproducible para el diagnóstico, integración, calidad y análisis predictivo de datos de citas de tres IPS y eventos de WhatsApp

## Stack

- Python
- pandas
- DuckDB
- scikit-learn
- pytest
- Git/GitHub

## Estructura

Se ha planteado una estructura modular, que nos permita segmentar e identificar de manera eficaz la programación u origen de todo para una mayor escalabilidad y mantenimiento
De igual manera, los destinos de las salidas generadas por el proyecto

- data/: datos locales.
- src/profiling/: perfilamiento.
- src/pipeline/: procesamiento RAW, SILVER y GOLD.
- src/model/: modelo predictivo.
- tests/: pruebas automatizadas.
- docs/: documentación E1-E6.
- outputs/: resultados generados localmente.
